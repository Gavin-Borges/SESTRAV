# SESTRAV Claims Register

All public-facing claims about SESTRAV must appear in this register before being added to
any document. Each row requires a primary literature citation, explicit scope boundary,
limitation statement, and location tracking. Claims without all four fields are not cleared
for publication.

**The Four Questions (apply to every row):**
- Q1 Mechanism: Is the biological mechanism described correctly with a primary citation?
- Q2 Scope: Which viruses, alleles, lengths, assay types does this apply to?
- Q3 Limitation: Is there a corresponding acknowledgment of when it doesn't hold?
- Q4 Fairness: Is any comparison under equivalent evaluation conditions (or asymmetry disclosed)?
